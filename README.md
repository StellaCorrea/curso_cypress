# 🧪 Curso Cypress – Testes Automatizados

Projeto de estudos em **Cypress** focado na criação de testes automatizados end-to-end, cobrindo cenários de **login**, **cadastro** e **fluxos principais** da aplicação.

---

## 🎯 Objetivo
Aprender e praticar automação de testes com Cypress, aplicando boas práticas de QA e organizando os testes de forma escalável.

---

## 🛠️ Tecnologias
- Cypress
- JavaScript
- Node.js
- Git / GitHub
- Cypress Cloud

---

## 📂 Estrutura do projeto
```bash
cypress/
 ├─ e2e/
 │  ├─ LOGIN/        # Testes de login
 │  ├─ CADASTRO/     # Testes de cadastro
 │  └─ tela_principal.cy.js
 ├─ fixtures/        # Massa de dados
 ├─ support/         # Comandos customizados
